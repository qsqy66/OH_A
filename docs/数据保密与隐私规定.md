# 数据保密与隐私规定

## 一、保密范围

下列信息属于公司商业秘密，员工负有保密义务：

1. 公司战略规划、经营数据、财务数据与投融资信息；
2. 核心技术、源代码、算法、专利与未公开的产品方案；
3. 客户名单、合同内容、报价方案及客户提供的资料；
4. 员工薪酬、绩效等人事信息；
5. 其他公司明确标注为机密的信息。

## 二、数据分级

1. **公开**：可对外发布的信息，如已发布的产品文档、新闻稿。
2. **内部**：仅限公司内部员工知悉的信息，如内部制度、组织架构。
3. **机密**：仅限相关岗位员工知悉的信息，如财务数据、客户合同。
4. **绝密**：仅限高管及授权人员知悉的信息，如并购、核心算法。

## 三、个人信息保护

1. 公司收集、使用员工及客户个人信息，遵循合法、正当、必要原则。
2. 涉及个人敏感信息（身份证、银行账号、健康信息等）应脱敏存储与展示。
3. 未经本人同意，不得将个人信息用于约定以外的用途。

## 四、脱敏规范

对外展示、测试或分析数据时，应按以下规则脱敏：

- 手机号：保留前三位和后四位，中间以星号代替，如 `138****5678`；
- 身份证号：保留前六位和后四位；
- 银行卡号：仅保留后四位；
- 姓名：可使用姓氏加星号，如 `张*`。

## 五、保密期限

保密义务自员工知悉保密信息时起，贯穿整个任职期间，并在离职后继续有效。公司另有约定的，按约定执行。

## 六、违规责任

泄露公司机密或个人信息的，公司有权追究纪律及法律责任；造成损失的，依法承担赔偿责任。
