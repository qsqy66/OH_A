# 信息安全管理制度

## 一、总则

为保障公司信息系统、业务数据与客户信息安全，防范内外部安全风险，制定本制度。全体员工须遵守本制度及国家网络安全相关法律法规。

## 二、账号与密码管理

1. 所有系统账号实行一人一号，禁止共用账号。
2. 密码长度不少于 12 位，须包含大小写字母、数字与特殊字符，不得使用生日、工号等易猜信息。
3. 核心系统密码每 90 天强制更换一次，不得重复使用最近五次密码。
4. 禁止将密码明文记录在便签、文件或聊天记录中。

## 三、权限管理

1. 系统权限按最小权限原则分配，员工仅拥有完成本职工作所需的权限。
2. 岗位变动或离职时，信息部应及时回收或调整相关权限。
3. 临时权限需申请并设置有效期，到期自动失效。

## 四、数据外发与传输

1. 涉及客户数据、经营数据的外发须经部门负责人审批，并通过安全渠道传输。
2. 禁止通过个人邮箱、网盘、即时通讯工具传输公司机密数据。
3. 对外提供数据前须进行脱敏处理，去除身份证号、手机号、银行卡号等敏感信息。

## 五、终端与网络安全

1. 办公电脑须安装公司指定的杀毒软件并保持病毒库更新。
2. 禁止私接未经批准的无线设备或路由，禁止访问与工作无关的高风险网站。
3. 严禁点击来源不明的邮件链接或附件，疑似钓鱼邮件应立即上报信息部。

## 六、安全事件上报

发现账号异常、数据泄露、病毒攻击等安全事件，员工应第一时间联系信息部，不得擅自处理或隐瞒。信息部按应急预案处置并留存记录。

## 七、违规处理

违反信息安全规定的，视情节轻重给予警告、通报批评、扣减绩效或解除劳动合同处理；触犯法律的，依法追究责任。
