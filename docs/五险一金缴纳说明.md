# 五险一金缴纳说明

## 一、适用范围

公司依法为全体签订劳动合同的员工缴纳五险一金，包括：养老保险、医疗保险、失业保险、工伤保险、生育保险及住房公积金。

## 二、缴纳基数

1. 缴纳基数以员工上一年度月平均工资为基准。
2. 基数低于当地社平工资 60% 的，按 60% 缴纳；高于 300% 的，按 300% 缴纳。
3. 新入职员工按首月工资确定缴纳基数，次年统一调整。

## 三、缴费比例（以北京为例）

| 险种 | 单位比例 | 个人比例 |
| --- | --- | --- |
| 养老保险 | 16% | 8% |
| 医疗保险 | 9.8% | 2% + 3 元 |
| 失业保险 | 0.5% | 0.5% |
| 工伤保险 | 0.2%–1.9% | 个人不缴 |
| 生育保险 | 0.8% | 个人不缴 |
| 住房公积金 | 5%–12% | 5%–12% |

具体比例以当地最新政策为准，各城市略有差异。

## 四、公积金

1. 公司公积金缴存比例默认为 12%，员工可选择 5%–12% 区间，每年调整一次。
2. 公积金可用于购房、租房、还贷及大病提取，具体以当地公积金管理中心规定为准。

## 五、社保转移与停缴

1. 员工跨城市调动或离职的，可申请办理社保关系转移。
2. 离职当月社保按实际在职时间缴纳，次月停缴。
3. 员工应及时关注社保状态，避免断缴影响相关权益。

## 六、查询方式

员工可通过当地社保局官网、官方 App 或拨打 12333 查询个人缴费记录。如有疑问，可联系人力资源部薪酬福利专员。
