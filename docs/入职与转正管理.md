# 入职与转正管理

## 一、入职材料

新员工应在入职当天携带以下材料至人力资源部办理入职手续：

1. 本人有效身份证原件及复印件；
2. 最高学历、学位证书原件及复印件；
3. 最近一家单位的离职证明（应届生提供报到证或就业协议）；
4. 一寸免冠照片两张；
5. 指定银行的工资卡信息；
6. 体检报告（近三个月内，二级以上医院）。

材料不齐全的，应在入职后五个工作日内补齐，逾期未补齐可能影响工资发放。

## 二、入职办理流程

1. 人力资源部核验入职材料，签订劳动合同；
2. 领取工牌、门禁卡及办公电脑等设备；
3. 信息部开通企业邮箱、OA、钉钉、代码仓库及内部系统账号；
4. 直属主管介绍团队与岗位职责，安排带教人；
5. 参加新员工入职培训（含企业文化、信息安全、办公规范）。

## 三、试用期

1. 劳动合同期限三年及以上的，试用期不超过六个月；一年以上不满三年的，试用期不超过两个月。
2. 试用期工资不低于转正后工资的 80%，且不低于当地最低工资标准。
3. 试用期内双方可依法解除劳动合同，但应提前通知并办理交接。

## 四、转正评估

1. 员工在试用期满前一周，填写《转正申请》，由直属主管进行绩效与胜任度评估。
2. 直属主管在三个工作日内给出转正意见，交部门负责人审批。
3. 审批通过后，人力资源部发出转正通知，自试用期满次日起转正。
4. 评估不通过的，公司可依法延长试用期（累计不超过法定上限）或解除劳动合同。

## 五、转正后待遇

转正后，员工按岗位薪资标准执行全额工资，并按规定享受带薪年假、绩效奖金及其他福利。转正时间以劳动合同约定的试用期届满为准。
