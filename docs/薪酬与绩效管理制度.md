# 薪酬与绩效管理制度

## 一、薪酬结构

员工薪酬由以下部分构成：

1. **基本工资**：根据岗位职级、能力与市场水平确定。
2. **绩效工资**：与个人及团队绩效考核结果挂钩，按月或按季发放。
3. **津贴补贴**：包括餐补、交通补贴、通讯补贴、住房补贴等。
4. **奖金**：包括项目奖金、年终奖及专项奖励，根据公司经营状况与个人贡献发放。

## 二、发薪时间

公司于每月 10 日发放上月工资。遇法定节假日或周末，发薪日顺延至最近的工作日。工资通过银行代发至员工工资卡，员工应确保银行账户信息准确。

## 三、绩效考核

1. 考核周期分为月度、季度与年度考核。
2. 考核维度包括业绩达成、工作质量、协作能力与成长潜力。
3. 绩效等级划分为 S、A、B、C、D 五档：S 为卓越，A 为优秀，B 为合格，C 为待改进，D 为不合格。
4. 绩效结果影响绩效工资、晋升、调薪与年终奖。

## 四、绩效面谈与申诉

1. 每轮考核结束后，直属主管应与员工进行绩效面谈，反馈结果并制定改进计划。
2. 员工对考核结果有异议的，可在结果公布后五个工作日内向人力资源部提出申诉。
3. 人力资源部在收到申诉后十个工作日内组织复核并反馈结论。

## 五、调薪机制

1. 年度调薪每年进行一次，通常在绩效评估完成后统一执行。
2. 晋升调薪、岗位变动调薪按晋升与调岗制度执行。
3. 特殊贡献或市场薪酬倒挂的，可由部门负责人提出特批调薪申请。

## 六、薪酬保密

薪酬信息属于公司机密，员工不得互相打听、泄露本人或他人薪酬。违反薪酬保密规定的，视情节给予纪律处分。
