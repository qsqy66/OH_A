# 印章与合同管理

## 一、印章种类

公司印章包括：公章、合同专用章、财务专用章、法定代表人名章、发票专用章及各部门业务章。

## 二、印章保管

1. 公章、合同专用章由行政部指定专人保管；财务专用章、法定代表人名章由财务部保管。
2. 印章保管人应妥善保管，不得私自出借、转交或带离公司。
3. 印章存放于保险柜等安全设施中，使用时登记。

## 三、用印审批

1. 用印须在 OA 提交用印申请，注明文件名称、用途、份数及用印种类。
2. 一般业务用印由部门负责人审批；合同、对外承诺等重要文件由分管副总或总经理审批。
3. 涉及担保、对外投资、借贷等重大事项的用印，须经总经理办公会批准。

## 四、用印要求

1. 用印文件须内容完整、字迹清晰，不得在空白文件上用印。
2. 盖章位置应规范，多页文件须加盖骑缝章。
3. 用印后登记台账，注明时间、文件、份数与经办人。

## 五、合同管理

1. 合同起草应使用公司标准模板，特殊条款须经法务审核。
2. 合同签订前应完成用印审批，并留存电子及纸质原件。
3. 合同由行政部统一归档，按部门、类型、期限分类管理。

## 六、合同履行与归档

1. 业务部门负责跟踪合同履行，及时处理变更、续签或终止。
2. 合同原件应妥善保管，保存期限按国家规定执行。
3. 合同到期或终止的，应及时归档并更新台账。

## 七、印章遗失处理

印章遗失或被盗，保管人应立即报告行政部及分管领导，办理登报挂失并重新刻制，同时追究相关责任。
