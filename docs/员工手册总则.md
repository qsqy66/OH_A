# 员工手册总则

## 一、手册目的与适用范围

本手册旨在向全体员工明确公司的基本制度、行为规范与权利义务，帮助员工了解并遵守公司的管理规定。

本手册适用于与公司建立劳动关系的全体正式员工、试用期员工及实习生。劳务派遣及外包人员参照相关合同执行。

## 二、公司简介

公司是一家专注于企业数字化办公解决方案的科技公司，主营业务包括协同办公软件、数据智能分析与企业知识管理平台的研发与运营。公司总部位于北京，在上海、杭州、成都设有分支机构。

## 三、核心价值观

公司倡导并践行以下核心价值观：

1. **客户第一**：以客户需求为出发点，持续创造价值。
2. **坦诚协作**：对事不对人，开放沟通，跨团队协同。
3. **追求卓越**：高标准要求自己，持续改进工作方法。
4. **长期主义**：注重长期价值积累，拒绝短期投机行为。

## 四、员工基本行为准则

1. 遵守国家法律法规及公司各项规章制度，维护公司合法权益。
2. 爱岗敬业，诚实守信，不弄虚作假，不隐瞒重大事项。
3. 保守公司商业秘密，未经授权不得对外泄露公司经营、技术、客户等信息。
4. 尊重同事，禁止任何形式的歧视、骚扰与职场霸凌。
5. 合理使用公司资源，不得利用职务之便谋取私利。
6. 注重信息安全，妥善保管账号、密码及办公设备。

## 五、员工权利

1. 享有法律法规规定的劳动保护、休息休假、劳动报酬等权利。
2. 享有平等就业与晋升机会，不因性别、民族、宗教、年龄等因素受歧视。
3. 有权对不合理的工作安排或违纪行为提出申诉，公司对申诉内容保密。
4. 有权查阅与本人有关的考勤、薪酬、绩效等记录。

## 六、员工义务

1. 完成本岗位职责范围内的工作任务，服从合理的工作安排。
2. 遵守考勤、保密、信息安全等各项管理制度。
3. 妥善保管公司财物，离职时按规定办理交接与归还。
4. 及时、如实报告工作中的重大异常与风险事项。

## 七、手册的修订与解释

本手册由人力资源部负责维护与解释。公司可根据经营需要和法律法规变化对手册进行修订，修订内容经审批后通过公司内部系统或邮件向全体员工公示。员工如对手册内容有异议，可在公示后五个工作日内向人力资源部反馈。
