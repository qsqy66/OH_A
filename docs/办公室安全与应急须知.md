# 办公室安全与应急须知

## 一、消防安全

1. 办公区严禁使用明火，禁止在非吸烟区吸烟。
2. 消防通道、安全出口保持畅通，不得堆放杂物。
3. 熟悉所在楼层的灭火器、消火栓和疏散路线位置。
4. 下班前关闭电脑、空调、饮水机等设备电源，防止电气火灾。

## 二、应急疏散

1. 发生火灾时，立即拨打 119 并按响就近报警装置，同时通知行政部。
2. 疏散时不要乘坐电梯，用湿毛巾捂住口鼻，弯腰沿疏散通道撤离。
3. 撤离到指定集合点后，清点人数并向负责人报告。
4. 公司每年组织不少于一次消防演练，员工应积极参加。

## 三、用电安全

1. 禁止私拉乱接电线，禁止使用大功率违规电器。
2. 插线板不得超负荷使用，不得串联使用多个插线板。
3. 发现电线破损、插座松动或焦糊气味，立即停止使用并报修。

## 四、防盗安全

1. 妥善保管个人贵重物品，离开工位时锁好抽屉。
2. 笔记本电脑等设备下班后应锁入柜中或带离办公区。
3. 发现可疑人员或物品，及时通知行政部或安保人员。

## 五、急救与健康

1. 办公区配置急救药箱，存放于前台或指定位置，由行政部定期检查补充。
2. 员工突发身体不适时，应立即通知同事并拨打 120 急救电话。
3. 患有特殊疾病的员工，可自愿向行政部报备，以便紧急情况及时救助。

## 六、恶劣天气与突发事件

1. 遇台风、暴雨等极端天气，员工应关注公司通知，合理安排出行。
2. 因极端天气无法到岗的，应及时向直属主管报备，按弹性考勤处理。
3. 发生地震等突发灾害时，就近躲避、有序疏散，听从统一指挥。

## 七、安全责任

每位员工都是自身安全的第一责任人，同时负有互相提醒、及时报告的责任。对违反安全规定造成事故的，公司将依法依规追究责任。
