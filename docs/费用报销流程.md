# 费用报销流程

## 一、报销范围

以下费用可按规定申请报销：

1. 差旅费（交通、住宿、市内交通、餐补）；
2. 业务招待费；
3. 办公用品及耗材采购费；
4. 培训、会议及因公产生的其他费用。

## 二、报销凭证要求

1. 报销须提供合法有效的增值税发票，抬头为“本公司全称及纳税人识别号”。
2. 发票应内容真实、金额准确，不得使用假发票、代开发票。
3. 电子发票须为 PDF 或 OFD 原件，截图无效。
4. 发票应在开具后三个月内提交报销，逾期原则上不予受理。

## 三、报销流程

1. 员工在 OA「费用报销」模块填写报销单，上传发票及说明。
2. 直属主管审核费用真实性，部门负责人审批。
3. 财务部核对发票与单据，确认无误后打款。
4. 报销款原则上在审批完成后五个工作日内到账。

## 四、审批权限

| 单笔金额 | 审批人 |
| --- | --- |
| 500 元以下 | 直属主管 |
| 500–5000 元 | 部门负责人 |
| 5000 元以上 | 财务总监 / 分管副总 |

## 五、常见退回原因

1. 发票抬头或税号错误；
2. 发票过期或无法查验；
3. 缺少明细、合同或审批记录；
4. 超标准报销且无审批说明；
5. 重复报销。

## 六、注意事项

1. 不得虚报、多报、拆分报销规避审批，违者按公司纪律规定处理。
2. 出差报销须同时提交出差申请单，具体标准参照《差旅管理制度》。
3. 业务招待费须注明招待对象、事由与陪同人数。
