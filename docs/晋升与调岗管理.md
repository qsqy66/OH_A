# 晋升与调岗管理

## 一、晋升原则

1. 晋升以能力、绩效与潜力为核心依据，兼顾岗位需要与团队结构。
2. 晋升坚持公开、公平、公正，同等条件下优先考虑绩效优秀者。
3. 晋升通道分为管理序列与专业序列，员工可根据特长选择发展路径。

## 二、晋升条件

1. 在原岗位任职满一年（特殊情况可放宽）；
2. 最近两次绩效考核无 C 及以下；
3. 具备目标岗位所需的胜任力；
4. 通过晋升评审或答辩。

## 三、晋升流程

1. 每年两次晋升窗口（3 月、9 月），由直属主管提名或员工自荐。
2. 部门负责人审核提名，人力资源部组织评审。
3. 评审通过后公示五个工作日，无异议的正式生效。
4. 晋升后进入三个月考察期，考察期表现纳入后续评估。

## 四、调岗类型

1. **组织安排调岗**：因业务调整、组织优化由公司统一安排。
2. **个人申请调岗**：员工因职业发展需要主动申请。
3. **绩效不胜任调岗**：绩效考核连续不达标，经培训仍不胜任的调整岗位。

## 五、调岗流程

1. 调岗申请由调入、调出部门协商一致后，报人力资源部审批。
2. 审批通过后，员工与原部门完成工作交接，到新部门报到。
3. 跨城市调动的，按公司差旅与安置规定办理相关手续。
4. 调岗后薪资按新岗位标准执行，试用考察期一般为一个月。

## 六、降职与退出

1. 连续绩效不达标或严重违纪的，公司可按制度降职或解除劳动合同。
2. 降职应履行告知与沟通程序，并给予改进机会。

## 七、申诉

员工对晋升或调岗结果有异议的，可在结果公布后五个工作日内向人力资源部提出申诉，人力资源部在十个工作日内复核反馈。
