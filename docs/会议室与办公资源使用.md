# 会议室与办公资源使用

## 一、会议室预订

1. 会议室统一通过 OA 或钉钉的「会议室预订」模块预约，先到先得。
2. 单次预订时长原则上不超过两小时，超时需重新预订。
3. 预订后如无法使用，应至少提前半小时取消，避免资源浪费。
4. 重要会议可提前一周预订，并注明参会人数与设备需求。

## 二、会议室设备

1. 会议室配备投影、视频会议终端、白板等设备，使用前请检查设备是否正常。
2. 会议结束后应关闭投影、灯光、空调，整理白板与桌椅，恢复整洁。
3. 设备故障的，在 IT 服务台报修，并通知行政部。

## 三、访客接待

1. 访客来访须提前在 OA 登记，由接待人到大堂确认身份后领入。
2. 访客须佩戴临时访客证，活动范围限于接待区、会议室等公共区域。
3. 访客不得进入机房、财务室、研发区等敏感区域。

## 四、工位管理

1. 工位由行政部统一规划分配，员工不得私自调换或占用。
2. 工位应保持整洁，下班前清理桌面，妥善保管贵重物品。
3. 长期出差或外派的，工位可能被临时调配，需提前与行政部确认。

## 五、公共区域

1. 茶水间、休息区、打印区等公共区域使用后应及时清理。
2. 节约用水用电，随手关灯、关空调。
3. 不得在办公区吸烟，吸烟请前往指定吸烟区。

## 六、门禁与安全

1. 员工凭门禁卡进出办公区，不得尾随他人进入，不得代他人刷卡。
2. 门禁卡丢失应立即挂失并补办，补办费用由员工承担。
3. 非工作时间进入办公区的，应遵守加班及安全登记规定。
