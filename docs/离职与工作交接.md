# 离职与工作交接

## 一、离职类型

1. **主动辞职**：员工提前三十日以书面形式通知公司，试用期内提前三日通知。
2. **协商解除**：双方协商一致，签订解除协议后办理离职。
3. **公司解除**：因员工违纪、不胜任或经营调整等原因，公司依法解除劳动合同。
4. **合同到期**：劳动合同期满，双方不再续签。

## 二、离职申请流程

1. 员工在 OA 系统提交离职申请，注明离职原因与拟离职日期。
2. 直属主管在三个工作日内审批，并安排工作交接计划。
3. 部门负责人、人力资源部依次审批。
4. 人力资源部确认最后工作日，通知员工办理交接。

## 三、工作交接内容

员工离职前须完成以下交接：

1. 未完成工作事项及进度说明；
2. 客户、项目、代码、文档等资料移交；
3. 办公电脑、工牌、门禁卡、U 盾、印章等资产归还；
4. 企业邮箱、OA、钉钉、代码仓库等账号注销或移交；
5. 财务借款、预支费用结清。

## 四、离职结算

1. 工资结算至最后工作日，随次月发薪日一并发放。
2. 未休年假按相关规定折算为工资，或安排离职前休完。
3. 绩效奖金、项目奖金按公司薪酬制度及相关约定结算。
4. 公司应在员工办结交接后十五日内出具离职证明。

## 五、竞业限制与保密义务

1. 对签署竞业限制协议的员工，公司按约定支付竞业限制补偿金。
2. 竞业限制期限不超过两年，范围限于与公司存在竞争关系的业务。
3. 离职后员工仍负有保密义务，不得泄露、使用公司商业秘密。

## 六、离职后事项

员工离职后如发现遗留问题需配合的，公司可联系本人协助处理。离职员工在办结交接前不得提前离岗，擅自离岗造成损失的，公司有权依法追责。
